## Robot Motors Control Project

### Описание
Проект демонстрирует управление скоростью робота с использованием Python и работу с Git (ветки и Pull Request).

### Этапы работы
- Создан локальный репозиторий
- Инициализирован Git
- Добавлены файлы проекта
- Выполнены коммиты изменений
- Создана ветка feature_speed
- Реализовано изменение скорости робота
- Выполнен Pull Request и слияние с main

### Код
Файл motors_control.py содержит класс RobotMotor и функцию плавного изменения скорости.

### Вывод
Я научилась работать с Git: создавать ветки, коммиты и Pull Request, а также реализовывать базовую логику управления скоростью робота.
